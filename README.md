# Taruna Stores – Financial Analysis Dashboard

## 📊 Project Overview
An interactive Power BI dashboard designed to analyze the financial performance of Taruna Stores.

## 📈 Key Analysis
- Sales and Orders performance
- Profit Margin by Country
- Discount Band Analysis
- Profit Margin by Segment and Product
- Sales Trends
- Top 3 Products by Sales

## 🛠️ Tools Used
- Power BI
- Excel
- DAX
- Data Visualization

## 🎯 Objective
To provide clear insights into sales, profitability, discounts, products, and business segments for better decision-making.
